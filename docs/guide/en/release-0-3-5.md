---
title: "Arcnix 0.3.5 release notes"
description: "A macOS disk image, a pinnable fullscreen bar and a fix for opening Code Editor on a read-only desktop."
order: 8
---

- Apple Silicon downloads now come as a DMG. Open it and drag Arcnix to Applications.
- The fullscreen status bar floats at the top center. Pin it to keep it visible, or unpin it and move the pointer anywhere along the top edge to reveal it. On macOS, Arcnix restores the previous window mode when you exit desktop fullscreen.
- The Apps search field now sits between the dialog title and the close button. Code Editor opens reliably from a read-only local desktop.
