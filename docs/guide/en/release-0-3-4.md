## Images and documents

Open a photo or PDF from Files on a local or SSH desktop. Image Viewer can rotate, zoom and move between neighboring images. PDF Reader can jump to a page, fit its width and unlock password-protected documents. Both can fill the desktop while leaving the workspace tabs accessible. [Watch the walkthrough](/#walkthrough)

## Files and the desktop

Set a default layout, sort order, icon size and columns, then change individual folders from their toolbars. **Ctrl+H** toggles hidden items everywhere. Open the local desktop in read-only mode to browse your own files before connecting to a server. Running apps now appear in the Dock, where you can pin them for later. [Files and viewer controls](/docs/workspace/)

## Server tools and updates

Docker groups containers by Compose project and can show mounts, logs and statistics. App Center distinguishes system services from container installations. The desktop now uses Sapid 0.9.1 and Glory 0.9.1.

Windows x64, Apple Silicon and Linux x64/ARM64 packages and checksums are available on the release page. [Download Arcnix v0.3.4](https://github.com/arcnix-org/arcnix/releases/tag/v0.3.4)
