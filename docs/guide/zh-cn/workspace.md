## 上传和下载

打开**传输文件**，左右两栏分别显示本地和远程目录。先进入目标目录，再从另一栏把文件或文件夹拖过去。展开传输任务可看每个文件的进度。如果目标位置有同名文件，请先确认冲突处理方式。

## 编辑远程文件

在**资源管理器**里右键一个 UTF-8 文本文件，选择**用 Code 打开**。按 **Ctrl+S** 通过 SFTP 保存。如果编辑期间服务器上的文件发生变化，先核对远端内容。超过 1 MiB 的文件使用分块只读预览。

按 **Ctrl+Shift+F** 搜索远程工作目录，点击结果可跳到对应行。编辑 Markdown 时，先按 **Ctrl+K**，再按 **V**，即可在旁边查看渲染效果。

## 打开终端

右键文件夹，选择**在此处打开终端**，远程 shell 就会从该目录启动。也可以在 Code 中打开集成终端。命令使用当前 SSH 账号运行。服务器有 tmux 时，桌面终端支持恢复远程会话。

## 播放远程视频

在 Windows x64 上，双击远程目录中的 MP4 或 MKV，也可以右键选择**播放**。播放器会按播放位置通过 SFTP 分段读取，拖动时间轴就能跳播。MP4 使用 WebView2，MKV 由随客户端提供的 libmpv 解码。[观看播放和编辑实录](https://arcnix.org/zh-cn/)
