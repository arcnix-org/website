## 设置文件夹视图

打开**文件管理器**的齿轮设置，选择默认视图、图标大小、排序和显示列。要单独调整当前文件夹，请用其工具栏。例如，把图片目录切到平铺图标并调大图标，下次进入时仍保留这一选择。在文件夹菜单选择**使用默认视图**，即可恢复继承默认设置。

在文件管理器按 **Ctrl+H** 可统一显示或隐藏所有目录中的隐藏项。隐藏项的图标会变淡，包括点号开头的文件和文件夹，以及本机 Windows 中带有隐藏属性的项目。

## 查看图片和 PDF

双击图片打开**图片查看器**。用左右方向键切换同目录中的图片，滚轮缩放，放大后拖动图片可查看细节。按 **0** 适应窗口，按 **1** 恢复原始大小。支持最大 8 MiB 的单张图片。

双击 PDF 打开 **PDF 阅读器**。输入页码后按 **Enter** 跳页，也可用 **Page Up** 和 **Page Down** 翻页。阅读小字时选择**适应页宽**，查看页面全貌时选择**适应页面**。支持最大 64 MiB 的 PDF，加密文档会提示输入密码。两种查看器都可在阿牛桌面内全屏，按 **Esc** 恢复原窗口。

## 上传和下载

打开**传输文件**，左右两栏分别显示本地和远程目录。先进入目标目录，再从另一栏把文件或文件夹拖过去。展开传输任务可看每个文件的进度。如果目标位置有同名文件，请先确认冲突处理方式。

## 编辑远程文件

在**资源管理器**里右键一个 UTF-8 文本文件，选择**用 Code 打开**。按 **Ctrl+S** 通过 SFTP 保存。如果编辑期间服务器上的文件发生变化，先核对远端内容。超过 1 MiB 的文件使用分块只读预览。

按 **Ctrl+Shift+F** 搜索远程工作目录，点击结果可跳到对应行。编辑 Markdown 时，先按 **Ctrl+K**，再按 **V**，即可在旁边查看渲染效果。

## 打开终端

右键文件夹，选择**在此处打开终端**，远程 shell 就会从该目录启动。也可以在 Code 中打开集成终端。命令使用当前 SSH 账号运行。服务器有 tmux 时，桌面终端支持恢复远程会话。

## 播放远程视频

在 Windows x64 上，双击远程目录中的 MP4 或 MKV，也可以右键选择**播放**。播放器会按播放位置通过 SFTP 分段读取，拖动时间轴就能跳播。MP4 使用 WebView2，MKV 由随客户端提供的 libmpv 解码。[观看视频播放实录](/zh-cn/videos/video-player/) · [观看编辑实录](/zh-cn/videos/remote-editor/)
