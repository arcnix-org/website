---
title: "Arcnix 0.3.5 更新说明"
description: "macOS DMG 安装包、可固定的全屏状态条，以及只读桌面启动 Code Editor 的修复。"
order: 8
---

- Apple Silicon 版改用 DMG。打开后，将 Arcnix 拖到「应用程序」。
- 全屏状态条在顶部居中悬浮。钉住即可常驻，取消固定后，将鼠标移到窗口顶部任意位置即可唤出。macOS 退出桌面全屏时会恢复原窗口模式。
- Apps 搜索框移到弹窗标题与关闭按钮之间。修复了只读本机桌面打开 Code Editor 时的崩溃。
