## Docker

- 可从镜像创建 Compose 项目。设置端口、卷、环境变量和重启策略后，可以先预览 Compose 文件，再启动容器。
- 可检查已拉取的镜像标签是否有更新。在镜像列表中可以拉取新版；在「项目」中更新受管的 Compose 项目，会使用新镜像重新创建相应容器。
- 可查看磁盘用量，清理未使用的镜像或构建缓存。移除单个镜像前，阿牛桌面会重新核对镜像 ID，并检查是否还有容器依赖它。
- 可管理当前 SSH 用户的镜像仓库登录。读取列表时，服务器只返回仓库和凭据助手的名称。在「网络」页可以查看子网和已连接的容器，也可以从运行中容器的详情页选择「Shell」，打开该容器的终端。

## SFTP

目录中出现无法按 UTF-8 解码的文件名时，文件浏览器会列出其余项目，并提示跳过了几项。如果下载整个目录，阿牛桌面会在写入任何文件前停止，指出受影响的目录，方便处理文件名后重试。

## Nginx

新增的 Nginx 应用可查看服务器或容器中 Nginx 的站点和日志。编辑站点后，可以核对差异、测试配置，再重新加载。
