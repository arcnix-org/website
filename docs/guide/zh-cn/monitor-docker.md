## 查看服务日志

打开**桌面 → 监控**，查看当前服务器的 CPU、内存、磁盘和网络。进入**服务**，选中一个 systemd 服务，再打开对应日志，即可查看近期消息。要查哪个进程正在监听某个地址，可在进程视图中查看端口详情。

在**设置 → 监控 → 资源刷新间隔**中，可将服务器桌面的默认采样间隔设为 3、5、10 或 30 秒。

## 检查容器

当 SSH 账号有权访问服务器的 Docker 套接字时，Arcnix 可以识别 Docker。打开 **Docker → 容器**，按名称或镜像找到容器并选中。这里可以查看状态、端口和挂载，点击**日志**可读取近期输出。启动、停止或重启前，核对目标容器再确认。

## 查找卷或端口

在**卷**中选择卷名，查看挂载位置和使用它的容器。在**端口**中查看已发布的映射。使用主机网络的容器，可到监控中查看服务器监听端口。

**项目**用于管理支持的 Compose 项目。如果桌面里没有 Docker，先检查服务是否运行、当前 SSH 账号是否有权访问套接字，然后到桌面设置重新检测应用。
