## 管理 Redis 数据与服务

新增 Redis 应用，可查看服务器和 Docker 中的 Redis 实例，浏览数据库与键，查看和编辑字符串、哈希、列表、集合及有序集合，并管理键的过期时间。应用还提供诊断信息和服务控制。新建键不会覆盖已有键，编辑字符串时检查键类型并保留原有过期时间。

## 在终端中使用 Ctrl+/

终端现在将 **Ctrl+/** 作为 **Ctrl+_** 发送给远端应用，修复 Codex CLI 等程序无法响应该快捷键的问题。

## 在配置只读时手动更新

配置处于只读模式时，仍可手动检查、下载和安装阿牛桌面更新。自动下载和空闲安装保持停用，更新过程不会写入只读配置。
