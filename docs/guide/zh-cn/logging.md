## 查看本次会话

打开**设置 → 日志设置 → 查看本次记录**，可以看到本次运行中的连接、传输等操作。退出客户端后会话列表会清空。开启时间显示后，新条目会带上时间戳。在 Windows 上，退出前可点击**导出本次记录…**，手动保存一份副本。

## 退出后保留记录

1. 打开**设置 → 日志设置 → 本地日志**，开启**自动保存日志到本机**。之后的操作会写入 `arcnix.log`。
2. 选择保存文件夹。手动输入路径后点击**应用**，清空路径再应用可恢复默认位置。
3. 设置每个文件的大小上限和保留的旧文件数。例如选择 50 MiB 和 5 个旧文件，写满后会新建日志，同时最多保留 5 个旧文件。
4. 从日志设置或活动页点击**打开本地日志**即可读取当前文件。如果尚无文件，开启自动保存后执行一次连接服务器等操作。

**恢复日志默认设置**会保留已有的日志文件。[观看日志设置实录](/zh-cn/videos/local-logs/)

## 查看配置修复详情

旧配置里可能含有当前版本无法识别的文件打开方式。启动时，客户端会先备份原配置，再移除失效的关联，并保留其他设置。需要查看修复详情时，开启**设置 → 常规 → 调试模式**。如果客户端提示设置只读，请恢复一份可用的配置备份。[配置与记录指南](/zh-cn/docs/records/)
