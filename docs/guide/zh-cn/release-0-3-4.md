## 图片与文档

从本机或 SSH 桌面上的文件管理器双击照片或 PDF 即可打开。图片查看器支持旋转、缩放和切换同目录的图片。PDF 阅读器支持跳页、适应页宽和密码解锁。全屏查看时仍可使用工作台标签页。[观看操作实录](/zh-cn/#walkthrough)

## 文件与桌面

在齿轮设置中选好默认布局、排序、图标大小和显示列，再从各文件夹的工具栏单独调整。按 **Ctrl+H** 可统一切换所有目录中的隐藏项。连接服务器前也能以只读模式打开本机桌面，浏览自己的文件。运行中的应用会出现在程序坞，可以固定以便下次打开。[文件与查看器操作指南](/zh-cn/docs/workspace/)

## 服务器工具与升级

Docker 可按 Compose 项目归组容器，并查看挂载、日志和统计。应用中心区分系统服务和容器安装。桌面依赖已更新至 Sapid 0.9.1 和 Glory 0.9.1。

发布页提供 Windows x64、Apple Silicon 和 Linux x64、ARM64 安装包及其校验值。[下载 Arcnix v0.3.4](https://github.com/arcnix-org/arcnix/releases/tag/v0.3.4)
