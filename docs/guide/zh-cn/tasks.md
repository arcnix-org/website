## 运行脚本

1. 打开**脚本**，选择已保存的脚本或内置模板，再选择要运行的服务器。
2. 最多可选 32 台已信任的服务器。填写脚本参数，核对全部目标，包括被当前筛选条件隐藏的服务器。
3. 运行预检查，逐台查看执行计划，确认后提交已就绪的目标。

提交任务需要服务器提供 systemd、`flock` 以及 root 或 sudo 权限。普通脚本以原 SSH 用户身份运行。软件安装和服务变更也使用这套审核流程。

## 断开后查询结果

服务器确认接收后，即使关掉阿牛桌面，任务也会继续运行。在**任务中心**展开批次，选择**查询批次结果**，即可读取日志和退出状态。如果断线时仍显示“提交中”，服务器可能已经接收了任务。先用原任务编号查询，再决定是否重试。

如果本地历史中已找不到这个批次，打开**任务中心 → 服务器记录**，选择原服务器和账号。在另一台已信任同一主机的客户端上，也可这样读取任务记录。

## 从备份恢复文件

目录备份使用服务器上的 restic。在**备份与恢复**中新建策略，填写源目录、仓库位置和密码文件路径，将密码文件权限设为 `400` 或 `600`。首次使用时按需初始化仓库，再运行备份并核对生成的快照。

1. 在**浏览快照**中选择来源服务器和快照，点击**浏览文件**选择文件或目录。选择目录会包含其中的内容。
2. 选择一个新的目标目录。核对快照编号、所选路径和恢复位置，再提交。
3. 查看恢复结果，并在新目录中核对文件。

数据库策略使用原生数据库工具导出逻辑备份。PostgreSQL 可恢复到新数据库；MySQL 和 MariaDB 导出恢复为 SQL 文件，供单独导入。
