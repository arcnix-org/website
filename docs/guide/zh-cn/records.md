## 备份客户端配置

打开**设置 → 常规 → 备份配置**。选择目录和文件名，预览内容，再保存 JSON 文件。文件包含服务器配置、脚本、偏好和备份策略。其中的私钥路径指向本机文件，私钥本身要单独备份。

恢复时选择**恢复配置**并读取 JSON。核对即将替换的内容，等当前操作结束后再应用。Arcnix 会保存原配置的副本，并保留本机现有的 SSH 主机信任记录。已保存的脚本或预设可能含有敏感文本，请妥善保管导出的文件。

## 查看服务器记录

打开**任务中心 → 记录存储**，选择服务器账号，查看任务和配置记录占用的空间以及保留预览。默认保留最近七天的记录、最新十条任务记录，以及每个目标路径最近三份可验证的配置备份。活动记录和恢复所需的记录会受到保护。

## 核对清理和导出结果

预览清理只读取元数据。需要移除记录时，逐台核对精确文件清单，再提交清理任务。清理需要管理员权限，删除后无法撤销。

如果清理中途停止，打开**任务中心 → 清理报告**，检查原任务。报告会显示哪些文件已移除，哪些可能仍在私有暂存目录中。对于可导出的剩余文件，可先审核并导出，下载经过校验的 ZIP。移除暂存区的原文件需要单独确认。
