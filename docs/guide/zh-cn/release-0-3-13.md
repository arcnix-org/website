## 将服务器图片设为壁纸

打开**设置 → 外观 → 壁纸 → 添加壁纸**，选择服务器上已有的图片。阿牛桌面会在本机缓存原图，并生成 320×180 的 WebP 缩略图供图库展示。不同路径或服务器上的相同图片共用一份缓存。

缩略图上的标签表示自定义壁纸。恢复主题壁纸会保留图库。移除自定义壁纸时，服务器上的原图会保留；最后一个引用移除后，本机缓存会自动清理。

同一页的强调色面板现提供 36 种预设颜色。

## 在工具栏查看传输进度

上传和下载图标各自用外圈显示对应方向的传输进度。在设置中，将鼠标移到恢复图标上，或用键盘聚焦它，即可看到具体会恢复哪一项。

## 查找 Windows 配置文件

Windows 默认配置文件现位于 `%APPDATA%\Arcnix\config.json`。正常启动时，阿牛桌面会迁移原默认位置的配置及相关数据。使用 `--config` 时，应用会继续使用指定的路径。
