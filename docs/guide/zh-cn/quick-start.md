## 连接前准备

在自己的电脑上安装阿牛桌面。准备好服务器地址、SSH 端口、用户名，以及密码或本机私钥。第一次使用可以选择一台平时就能通过 SSH 登录的服务器。[安装与下载](https://arcnix.org/zh-cn/docs/install/)

## 先体验本机桌面

在服务器页选择**体验本机桌面**，然后选择**只读模式**。打开文件管理器，双击本机照片或 PDF 即可体验查看器。需要修改本机文件或运行终端命令时，再选择**读写模式**。

## 添加服务器

1. 打开**服务器**，选择**添加服务器**，填一个容易辨认的名称。
2. 填写服务器地址、端口（通常是 `22`）和 SSH 用户名。使用密钥登录时，选择电脑上的私钥文件。
3. 保存后，在服务器列表中选中它，点击**连接**。出现提示时，输入登录密码或私钥口令。

首次连接时，将界面显示的主机密钥指纹与管理员提供的指纹核对。确认一致后，选择**信任并保存**，以后连接时阿牛桌面会再次校验。

## 试一次桌面操作

打开**桌面 → 资源管理器**，找到当前账号有权读取的远程文件夹。右键选择**在此处打开终端**，输入 `pwd`。远程终端打印的路径应该与刚才选中的目录一致。

如果连接超时，先核对地址、端口和网络连通性。如果 SSH 已连接但文件列表无法加载，检查服务器是否启用了 SFTP，以及当前账号是否有目录读取权限。
