## 打开服务器的浏览器

通过 SSH 连接服务器，从它的桌面打开**浏览器**。Windows 和 Linux 客户端会通过选中的 SSH 连接访问网页。在地址栏中，输入你从服务器本机访问服务时使用的网址。例如，服务监听服务器回环地址的 8080 端口时，输入 `http://127.0.0.1:8080`。

## 确认地址和端口

使用服务器能访问的主机名或 IP。如果服务使用自定义端口，把端口也写进地址。明确填写 `http://` 或 `https://` 可以指定协议。页面打不开时，先确认 SSH 仍已连接，再核对服务是否运行、监听地址和端口是否与网址一致。

## 切换标签页或服务器

在同一服务器的浏览器中新建标签页，可以沿用该服务器的浏览会话。Linux 客户端为每台服务器分别保存浏览数据。要访问另一台服务器的回环地址，请切换到那台服务器的桌面再打开浏览器。Linux 客户端支持 Wayland 和 X11。[查看工作台](/zh-cn/workspace/)
